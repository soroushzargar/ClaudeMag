# StageGuard: Learning Stage Transitions for Long-Horizon Robot Tasks via Agentic Distillation

**arXiv:** 2609.20791  
**Submitted:** September 17, 2026  
**Authors:** Wenbo Cui, Jing Xu, Rui Zhao, Yunchao Liu, Chaobin Ye, Xinyu Zhang, Mingkui Tan  
**Affiliation:** South China University of Technology; Tencent Robotics X  
**Venue:** arXiv preprint

---

## Headline Finding

StageGuard learns to make accurate, low-latency stage-transition decisions for long-horizon hierarchical robot tasks by distilling structured reasoning traces from a large VLM teacher into a compact student VLM, achieving substantial improvements in stage-transition prediction accuracy on BEHAVIOR-1K and validated in closed-loop control on real robots, without requiring manually designed completion signal checkers or cloud-deployed reasoning.

---

## Key Findings (Pyramid Layer 2)

1. **Stage transitions are the critical bottleneck in hierarchical robot planning.** Modern hierarchical frameworks decompose long-horizon tasks into subtasks, each handled by a dedicated low-level policy. The transition decision — when to terminate the current subtask and invoke the next — is typically governed by hand-crafted rules that fail under perceptual noise, object displacement, and out-of-distribution configurations.

2. **Large VLMs have misaligned decision boundaries for stage transitions.** While frontier VLMs (e.g., GPT-4V, Qwen-VL-Max) can reason about object states and spatial relationships, their default decision logic is tuned for general Q&A rather than subtask completion criteria. They also run on cloud infrastructure, introducing 1–3 seconds of latency per query — incompatible with the 10 Hz control loop typical of manipulation platforms.

3. **Agentic distillation transfers task-aligned reasoning to a compact model.** StageGuard structures the teacher's reasoning as a three-layer agentic trace: a state layer (observation history, robot kinematics, spatial relations), a task layer (mapping current task plan to subtask rationales), and a decision layer (assessing completion and deciding transition). A lightweight local student VLM is supervised on these traces and learns to produce compact self-explanations sufficient for accurate decision-making.

4. **Structured self-explanation at inference enables interpretable monitoring.** The student generates a brief natural-language explanation alongside each transition decision, providing human-readable justification that can be logged for safety monitoring and post-hoc debugging — a property absent from rule-based transition checkers.

## Methodology (Pyramid Layer 3)

### Problem Formulation

Consider a long-horizon task decomposed into $M$ subtasks $\{T_1, \ldots, T_M\}$ executed sequentially. At time step $t$, the robot is executing subtask $T_i$ and observes $o_t = (I_t, \mathbf{q}_t, \mathbf{p}_t)$ where $I_t$ is an RGB image, $\mathbf{q}_t$ is the joint configuration, and $\mathbf{p}_t$ is end-effector pose. A transition monitor $f$ must decide:
$$d_t = f(o_{t-H:t}, T_i, T_{i+1}) \in \{0, 1\}$$
where $d_t=1$ triggers a transition to $T_{i+1}$ and $H$ is the observation history window.

### Three-Layer Teacher Reasoning

The teacher VLM processes $(o_{t-H:t}, T_i, T_{i+1})$ through three sequential prompting stages:

**State Layer:** Extract structured state representation:
$$z_{\text{state}} = \text{VLM}_T\!\left(\text{prompt}_{\text{state}}, o_{t-H:t}\right)$$
capturing: current object poses, grasp contacts, completion indicators (e.g., "cup is inside cabinet"), spatial relationships (e.g., "gripper is 3 cm above handle").

**Task Layer:** Map state to subtask semantics:
$$z_{\text{task}} = \text{VLM}_T\!\left(\text{prompt}_{\text{task}}, z_{\text{state}}, T_i, T_{i+1}\right)$$
capturing: which aspects of $z_{\text{state}}$ are relevant to completing $T_i$, what conditions define $T_i$ completion, what the preconditions for $T_{i+1}$ are.

**Decision Layer:** Issue transition decision with justification:
$$z_{\text{decision}}, d_t = \text{VLM}_T\!\left(\text{prompt}_{\text{decision}}, z_{\text{task}}\right)$$
producing a binary transition verdict plus a natural-language rationale.

### Student Fine-Tuning

Training data is generated by running the teacher on all demonstration trajectories in the training set, collecting $(o_{t-H:t}, T_i, T_{i+1}) \to (z_{\text{decision}}, d_t)$ pairs. The student is fine-tuned with:
$$\mathcal{L}_S = \mathcal{L}_{\text{CE}}(d_t, \hat{d}_t) + \lambda \cdot \mathcal{L}_{\text{align}}(z_{\text{decision}}, \hat{z}_{\text{decision}})$$
where $\mathcal{L}_{\text{CE}}$ is cross-entropy on the binary decision and $\mathcal{L}_{\text{align}}$ is a token-level alignment loss on the compressed justification text.

---

## Technical Formulation

The Observed Articulation Span objective generalizes to a monitoring confidence score. The student VLM produces a soft confidence:
$$c_t = \sigma\!\left(w^\top h_t\right), \quad h_t = \text{Student}(o_{t-H:t}, T_i, T_{i+1})$$
where $h_t \in \mathbb{R}^d$ is the last-layer hidden state and $w \in \mathbb{R}^d$ is a learned linear probe. The transition is triggered when $c_t \geq \tau$ (threshold $\tau$ set by validation).

The alignment loss uses a token-level cross-entropy between teacher-generated and student-generated explanation tokens, weighted by the teacher's per-token confidence:
$$\mathcal{L}_{\text{align}} = -\sum_j \hat{p}_j \log p_j^{\text{student}}$$
where $\hat{p}_j$ are teacher token probabilities and $p_j^{\text{student}}$ are student probabilities for the $j$-th explanation token.

## Learning or Inference Procedure

1. Collect demonstration trajectories for target tasks.
2. Run teacher VLM (cloud-deployed) on all trajectories to generate structured reasoning traces.
3. Fine-tune compact student VLM (runs locally on robot) on trace-decision pairs.
4. At inference: student VLM runs on-robot at each control step; trigger transition when $c_t \geq \tau$.
5. Log student explanation text for safety records and debugging.

---

## What the Guarantee Says

StageGuard does not prove formal correctness guarantees. The paper demonstrates that the student's F1 on stage-transition detection on held-out BEHAVIOR-1K trajectories is within 2.3% of the teacher, while inference latency drops from 1.8 seconds (cloud VLM) to 87 ms (local student), enabling real-time monitoring at 11 Hz.

## Experimental Findings

### Benchmarks
- **BEHAVIOR-1K simulation:** 1,000 household activity instances, 50 task categories, 500+ object types
- **Real robot validation:** Franka Panda executing 5 manipulation tasks (dish loading, cabinet packing, drawer organization)

### Main Results (BEHAVIOR-1K, F1 on stage-transition prediction)

| Method | F1 (sim) | Latency (ms) | Task SR (sim) |
|--------|---------|------------|-------------|
| Rule-based checker | 71.3 | 2 | 48.2 |
| GPT-4V (cloud, zero-shot) | 79.1 | 1820 | 52.7 |
| VLM fine-tuned (no reasoning) | 81.6 | 91 | 57.4 |
| **StageGuard** | **88.4** | **87** | **67.1** |

Task success rate (SR) refers to full long-horizon episode completion.

## Ablations and Interpretation

- **Removing state layer:** F1 drops by 4.1 points; the model struggles with spatial relationship reasoning without structured state extraction.
- **Removing task layer:** F1 drops by 3.6 points; the model cannot ground subtask completion criteria without explicit task-plan mapping.
- **Direct teacher distillation (no three-layer structure):** F1 is 83.9, below full StageGuard; unstructured traces dilute relevant decision factors with spurious reasoning steps.
- **History window $H$:** $H=5$ frames optimally balances temporal context with inference speed; $H=1$ loses 4.8 F1 points, $H=10$ improves only 0.4 F1 at 2× latency.
- **Student model size:** A 3B-parameter VLM achieves full StageGuard F1; 1B parameter model loses 3.2 F1 points; 7B adds only 0.5 F1 points at 3× latency.
