# Stay Within Your Bounds: Distance-Guided Decoding for Guaranteed Context-Free Grammar Compliance

**arXiv:** 2608.28229  
**Authors:** Vincenzo Collura, Karim Tit, Eleonora Giunchiglia, Mike Papadakis, Maxime Cordy  
**Submitted:** August 2026  
**Venue:** EMNLP 2026 Findings (Long Paper)  
**Area:** Constrained Generation, Structured Output, NLP, Formal Methods

## Summary

Grammar-constrained decoding ensures that a language model's token-by-token generation produces an output accepted by a target context-free grammar (CFG). This paper identifies a critical flaw in existing approaches—they can generate valid prefixes that are *infeasible*, meaning no completion within the token budget can form a grammatically valid string—and proposes a lookahead-guided decoding framework that computes bounded distances to acceptance and uses them to prune infeasible tokens and guide beam search. Every output generated by the resulting decoder is guaranteed to be syntactically valid.

## Problem

Structured generation tasks—producing JSON, SQL, regular expressions, or linear temporal logic (LTL) formulas—require outputs that are syntactically valid. Grammar-constrained decoding tracks which tokens are permitted at each step by maintaining the state of a pushdown automaton (PDA) derived from the CFG. At each decoding step, only tokens that keep the PDA in a state from which the grammar can still accept are permitted.

The existing approach has two failure modes:
1. **Tokenizer-grammar mismatch:** The LM's subword tokenizer may not align with the grammar's terminals, causing tokens to span multiple grammar symbols and creating prefix states where the PDA is in a non-final configuration after consuming the last available token.
2. **Finite budget exhaustion:** Even if each individual token is locally valid, the PDA may enter a configuration from which acceptance requires more tokens than remain in the budget. The model generates a prefix that cannot be completed.

Both cases produce syntactically *invalid* outputs despite using a grammar mask.

## Method

The paper reformulates the constraint as: at each step, only permit tokens that leave the PDA within *distance* $d$ of an accepting state, where $d$ is bounded by the remaining token budget. To compute distances efficiently, the paper:

1. **Constructs bounded PDA summaries:** For each reachable PDA configuration $(q, \gamma)$ (state $q$, stack content $\gamma$), precomputes a reachability label and an upper-bound estimate of the minimum number of additional tokens needed to reach acceptance.
2. **Online horizon-aware pruning:** At each decoding step with budget $B$ remaining, tokens that would push the PDA into a configuration with distance $> B$ are masked. This ensures the remaining sequence can always be completed within budget.
3. **Distance-guided beam search:** Among the remaining feasible tokens, beam search is biased toward candidates that reduce the distance to acceptance, improving both syntactic validity and completion quality.

The framework applies to any CFG representable as a PDA, including JSON schemas, SQL dialects, and LTL formulas.

## Technical Formulation

Define a PDA $\mathcal{A} = (Q, \Sigma, \Gamma, \delta, q_0, F)$ for the target grammar. For each configuration $c = (q, \gamma) \in Q \times \Gamma^*$, define:

$$d(c) = \min\{n \in \mathbb{N} : \exists w \in \Sigma^n, (q, \gamma) \xrightarrow{w} (q_f, \varepsilon) \text{ for some } q_f \in F\}$$

The paper computes an upper bound $\hat{d}(c) \geq d(c)$ by summarizing the PDA reachability structure with bounded lookahead. At decoding step $t$ with remaining budget $B = T - t$, a token $a$ with successor configuration $c'$ is permitted if $\hat{d}(c') \leq B$.

The beam search score is augmented with a distance term:

$$s'(a) = s(a) - \lambda \cdot \hat{d}(c')$$

where $s(a)$ is the log-probability of token $a$ and $\lambda$ balances fluency against distance minimization.

## Results

Experiments on JSON, SQL, and LTL generation:
- **Syntactic validity:** The decoder achieves 100% validity on all benchmarks, compared to partial validity under greedy and masked-softmax baselines that do not handle the budget-exhaustion failure mode.
- **Completion quality:** Distance-guided beam search improves task-specific metrics (JSON schema match rate, SQL execution accuracy, LTL satisfaction rate) over prior constrained decoding baselines.
- **Runtime:** The precomputed PDA summaries add a one-time overhead; online overhead per step is proportional to beam width times the number of reachable configurations, which is manageable for practical grammar sizes.

## Implications

Distance-guided decoding closes a correctness gap in grammar-constrained generation that has been overlooked in prior work. The framework is grammar-agnostic and integrates with any autoregressive LM. For applications requiring hard syntactic guarantees—code generation, structured data extraction, symbolic planning—this provides a practical path to sound constrained generation.
